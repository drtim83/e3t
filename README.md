## 📦 Deploy to GitHub Pages (Free)

1. **Push this repo to GitHub:**
   ```bash
   cd effort_planner_web
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git
   git push -u origin main
   ```
2. **Enable GitHub Pages:**
   - Go to your repo → **Settings** → **Pages**
   - Source: **Deploy from a branch** → **main** → **/(root)** → **Save**
3. Wait ~1-2 minutes. Your tool will be live at `https://YOUR_USERNAME.github.io/REPO_NAME/`

## 💻 Local Usage
Simply double-click `index.html` or run:
```bash
./e3t
```

## ✨ Features
- **4 Tabs**: Project config, Rate card, Effort grid, P&L summary
- **Live Calculations**: Revenue, cost, margin update instantly
- **Save/Load Projects**: Stored securely in your browser
- **Export**: Excel (`.xlsx`) & PDF via print dialog
- **Add/Edit/Delete**: Manage rate cards and resources dynamically

## 🔒 Privacy
- 100% client-side. No data is sent to any server.
- Project data is saved in your browser's local storage.
